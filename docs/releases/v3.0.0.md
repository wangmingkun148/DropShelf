DropShelf 3.0.0 用 C 重写了整个程序。功能和用法都和 2.8.2 一样，原来的设置会保留。

### 有什么不同

- **动画更流畅**：界面改用 Direct2D 绘制、DirectComposition 合成，置物架弹出和展开收起、主窗口翻牌、拖动卡牌都更跟手。
- **不再需要 .NET**：程序只有一个 DropShelf.exe，安装包和便携版都小得多。

### 升级

- 直接运行安装包覆盖安装，安装程序会关闭正在运行的 DropShelf。设置、最近关闭的置物架和语言包都沿用原来的文件，不用重新设置。
- 便携版：退出旧版后，用新的 DropShelf.exe 替换旧的即可。
- 程序没有代码签名，第一次运行新程序时 Windows 可能会再提示一次“Windows 已保护你的电脑”：点“更多信息”，再点“仍要运行”。

### 反馈

C 版是全新的代码。如果发现和 2.8.2 不一样的地方，欢迎到 [Issues](https://github.com/wangmingkun148/dropshelf/issues) 反馈，最好附上 `%LOCALAPPDATA%\DropShelf\Logs` 里的日志。想继续用原来的 C# 版，可以下载 [2.8.2](https://github.com/wangmingkun148/dropshelf/releases/tag/v2.8.2)。

DropShelf 3.0.0 is a complete rewrite in C. It does everything 2.8.2 did and works the same way, and your settings are kept.

### What's different

- **Smoother animations**: the interface is now drawn with Direct2D and composed with DirectComposition, so shelves pop up, expand and collapse more fluidly, and flipping cards and dragging them in the main window feel more responsive.
- **No .NET needed**: the program is a single DropShelf.exe, and both the installer and the portable version are much smaller.

### Upgrading

- Run the installer over your current installation. It closes the running DropShelf first. Your settings, recently closed shelves and language packs carry over.
- Portable version: quit the old version, then replace its DropShelf.exe with the new one.
- DropShelf isn't code-signed, so Windows may show "Windows protected your PC" once more the first time you run the new program. Click "More info", then "Run anyway".

### Feedback

The C version is all-new code. If something behaves differently from 2.8.2, please open an [issue](https://github.com/wangmingkun148/dropshelf/issues) and attach the logs from `%LOCALAPPDATA%\DropShelf\Logs`. The original C# version is still available as [2.8.2](https://github.com/wangmingkun148/dropshelf/releases/tag/v2.8.2).
