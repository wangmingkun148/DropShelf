DropShelf 3.1.4 让 Linux 版能接住跑在 XWayland 里的程序（Obsidian、WPS 等）的拖动。Windows 版照常更新。

### Linux 版

- **X11（XWayland）应用的拖放可以用了**：以前在这些程序里按住晃动叫不出置物架，把文字、图片拖到已经打开的置物架上也没有反应。原因是 Hyprland 只把 Wayland 源的拖动转给 X11 应用，反方向没有实现。现在程序里带了一个 X11 拖放桥：探针亮着或者光标落在置物架上时会临时放一个看不见的 X11 窗口接住拖动，读出文字、文件列表和图片交给置物架。在 Obsidian 里挪图片、往桌面拖文件这类普通拖动不受影响。
- **拖动期间置物架先不要键盘**：X11 拖动时一开置物架，Hyprland 会把键盘从 XWayland 收走、直接结束那次拖动，东西放不下来。现在这种情况下第一次点一下置物架再要键盘。
- **拖入方向跟随顶部的“复制/移动”开关**：移动时来源程序松手后删掉原文，复制时保留。只对文字和图片生效；文件拖进来只记路径，始终按复制。
- **设置里加“全屏时也响应”**：全屏的笔记、浏览器在前台时也能晃动或按快捷键叫出置物架。全屏游戏和演示里建议关着。
- “拖到这里拆成新置物架”的提示窗改成透明窗口，不再是黑底一块。
- 手势暂停时会把前台程序的名字写进日志，某个程序里晃不出来时方便排查。

### 升级

- Linux：AppImage 下载后 `chmod +x` 再运行；deb/rpm/pacman 用发行版的包管理器升级；便携版解压后运行 `bin/dropshelf`。
- Windows：直接运行安装包覆盖安装；便携版替换 DropShelf.exe 即可。

遇到问题欢迎到 [Issues](https://github.com/wangmingkun148/DropShelf/issues) 反馈；Windows 请附上 `%LOCALAPPDATA%\DropShelf\Logs` 里的日志，Linux 请附上 `~/.local/state/dropshelf/logs` 里的日志。

DropShelf 3.1.4 lets the Linux version accept drags from apps running under XWayland (Obsidian, WPS and the like). The Windows version continues as before.

### Linux

- **Drag and drop from X11 (XWayland) apps now works**: shaking to bring up the shelf had no effect in those apps, and dropping text or images onto an open shelf did nothing. Hyprland only forwards drags from Wayland sources to X11 apps, not the other way round. DropShelf now carries a small X11 drop bridge: while the probe is showing, or while the pointer is over a shelf, it puts an invisible X11 window in place to catch the drag and hands the text, file list or image to the shelf. Ordinary drags such as moving an image around inside Obsidian or dragging files to the desktop are left alone.
- **No keyboard while an X11 drag is running**: opening a shelf mid-drag made Hyprland take the keyboard away from XWayland and end the drag, so nothing could be dropped. In that case the shelf now takes the keyboard on your first click.
- **Incoming drags follow the copy/move switch at the top of the shelf**: in move mode the source app removes the original after you let go, in copy mode it stays. This applies to text and images; files are only referenced, so dragging a file in is always a copy.
- **New “Respond in fullscreen” setting**: shake and the shortcut also bring up the shelf while a fullscreen app is in front. Leave it off during games and presentations.
- The “drop here to split into a new shelf” hint now uses a transparent window instead of a black panel.
- When gestures are paused, the foreground app's name goes into the log, which makes “it won't come up in this app” easier to diagnose.

### Upgrading

- Linux: `chmod +x` the AppImage and run it; use your distribution's package manager for deb/rpm/pacman; unpack the portable tarball and run `bin/dropshelf`.
- Windows: run the installer over your current installation; for the portable version, replace DropShelf.exe.

If you run into a problem, please open an [issue](https://github.com/wangmingkun148/DropShelf/issues). On Windows, attach the logs from `%LOCALAPPDATA%\DropShelf\Logs`; on Linux, from `~/.local/state/dropshelf/logs`.
