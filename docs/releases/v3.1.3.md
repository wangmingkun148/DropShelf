DropShelf 3.1.3 带来了原生 Wayland 的 Linux 版（由 @pingod 贡献），两边都加上了“全屏时暂停”。

### Linux 版（新）

- **原生 Wayland**：用 C + GTK 4 + gtk4-layer-shell 实现，不经过 X11 兼容层。置物架、探角和菜单是 layer-shell 的 overlay 层，天然置顶；主窗口、引导和“关于”是普通窗口，标题栏由程序自己画，可以拖动、双击最大化。
- **和 Windows 版功能对齐**：拖入拖出（文件、文件夹、文字、链接、图片，网页图片按图片收下）、撤销和最近关闭、合并拆分、观察文件夹探角、托盘、全局快捷键、主窗口和设置页、快速操作（压缩、解压、移动/复制、复制路径、图片压缩和转换、属性、打开方式）、缩略图、更新检查、开机自启和低性能模式。
- **晃动和边缘停留**：在 Hyprland 上读取鼠标设备并用 Hyprland IPC 取光标位置；没有权限或不在 Hyprland 时自动退回快捷键。
- **XWayland 程序的拖放**：Hyprland 不会把 WPS 这类 XWayland 程序发起的拖动交给 Wayland 窗口，DropShelf 会在探针和置物架上放一个看不见的 X11 窗口接住，从这些程序里拖文字、图片和文件进来也能弹出、放下；从置物架往这些程序里拖时自己发 Xdnd，能放进 WPS。
- **混合拖出**：文件和文字一起选中拖到 XWayland 程序时，默认按置物架里的顺序一项一项地送进去（文档程序一次只肯插入一种内容），也可以在“手势与置物架”页改成合成 HTML、只送文件或只送文字。
- **两种风格都支持**：简洁和纸牌风格在 Linux 上都能用，换风格时同样是一串多米诺翻牌。
- **安装包**：AppImage（自带 GTK 等依赖，解压即用）、deb、rpm、pacman（`.pkg.tar.zst`）和便携 tar.gz，都在下面的文件里。deb/rpm/pacman 包依赖系统里的 GTK 4、gtk4-layer-shell、gdk-pixbuf、bsdtar（libarchive）、curl、fontconfig 和 libxcb。

Linux 上的已知差异（详见仓库里的 linux/README-linux.md）：

- 没有 Mica/Acrylic 材质，主窗口是半透明纯色；想要模糊可以在 Hyprland 里加 `layerrule = blur, dropshelf`。
- 纯 Wayland 桌面不能指定普通窗口的位置，主窗口由合成器摆放。
- 拖出时没有跟手的缩略图，也不能拖到桌面空白处（请拖进文件管理器）。
- 前台程序只能拿到 app_id，屏蔽列表按它匹配。
- 快捷方式的图标不跟着风格换（Linux 的 .desktop 图标由桌面环境按名字查）。
- 界面默认用 CPU（Cairo）绘制，避开部分显卡驱动下 GTK 渲染崩溃的问题；想换回显卡渲染可以设置 `GSK_RENDERER` 环境变量。

### Windows 版

- **全屏时暂停**：全屏的程序（游戏、全屏视频、演示）在前台时，晃动、边缘停留和快捷键都不弹出置物架，玩游戏时按住鼠标甩动也不会再触发。默认开启，可以在“手势与置物架”页关掉；按应用屏蔽照旧可用。Linux 版原来就会在全屏时暂停，现在也能用这个开关关掉。
- 设置页输入框的复制和粘贴改为和程序其他地方共用同一套剪贴板代码，用起来没有变化。

### 升级

- Windows：直接运行安装包覆盖安装，安装程序会关闭正在运行的 DropShelf；便携版替换 DropShelf.exe 即可。
- Linux：AppImage 下载后 `chmod +x` 再运行；deb/rpm/pacman 用发行版的包管理器安装或升级；便携版解压后运行 `bin/dropshelf`。

遇到问题欢迎到 [Issues](https://github.com/wangmingkun148/DropShelf/issues) 反馈；Windows 请附上 `%LOCALAPPDATA%\DropShelf\Logs` 里的日志，Linux 请附上 `~/.local/state/dropshelf/logs` 里的日志。

DropShelf 3.1.3 adds a native Wayland version for Linux (contributed by @pingod), and both versions gain “Pause in fullscreen”.

### Linux (new)

- **Native Wayland**: built with C, GTK 4 and gtk4-layer-shell, with no X11 compatibility layer. Shelves, the peek corner and menus are layer-shell overlays, so they stay on top; the main window, onboarding and About are ordinary windows with the title bar drawn by the app (drag to move, double-click to maximize).
- **Same features as the Windows version**: drag in and out (files, folders, text, links, images; images dragged from a browser are taken as images), undo and recently closed, merge and split, watched-folder peek corner, tray, global shortcuts, main window and settings pages, quick actions (compress, extract, move/copy, copy path, image compress and convert, properties, open with), thumbnails, update checks, autostart and low-performance mode.
- **Shake and edge hold**: on Hyprland, DropShelf reads the mouse device and asks Hyprland IPC for the cursor position; without permission, or outside Hyprland, it falls back to the shortcut.
- **Drag and drop with XWayland apps**: Hyprland doesn't hand drags started in XWayland apps such as WPS to Wayland windows, so DropShelf places an invisible X11 window over the probe and the shelf to catch them; text, images and files dragged from those apps now open a shelf and land on it. Dragging from a shelf into those apps uses DropShelf's own Xdnd, so items can be dropped into WPS.
- **Mixed drag-out**: when files and text are dragged together onto an XWayland app, they are sent one by one in shelf order by default (document apps accept one kind at a time). The Gestures & shelf page can switch this to a combined HTML payload, files only or text only.
- **Both looks work**: the simple and cards looks are both available on Linux, and switching flips the windows like a row of dominoes.
- **Packages**: AppImage (GTK and other dependencies included, ready to run), deb, rpm, pacman (`.pkg.tar.zst`) and a portable tar.gz, all attached below. The deb/rpm/pacman packages need GTK 4, gtk4-layer-shell, gdk-pixbuf, bsdtar (libarchive), curl, fontconfig and libxcb from the distribution.

Known differences on Linux (see linux/README-linux.md in the repository):

- No Mica/Acrylic material; the main window uses a translucent solid color. Add `layerrule = blur, dropshelf` in Hyprland for blur.
- Plain Wayland clients can't choose an ordinary window's position, so the compositor places the main window.
- No drag icon while dragging out, and dropping onto empty desktop space doesn't work (drop into a file manager window instead).
- Only the app_id of the foreground app is available; the block list matches on it.
- Shortcut icons don't follow the look (Linux .desktop icons are looked up by name by the desktop environment).
- The interface is drawn on the CPU (Cairo) by default to avoid GTK rendering crashes with some graphics drivers; set the `GSK_RENDERER` environment variable to use the GPU renderer instead.

### Windows

- **Pause in fullscreen**: while a fullscreen app (a game, fullscreen video or presentation) is in front, shake, screen-edge pause and the keyboard shortcut don't open a shelf, so flicking the mouse with a button held in a game no longer triggers anything. On by default; turn it off on the Gestures & shelf page. Excluded apps work as before. The Linux version already paused in fullscreen and now has the same switch.
- Copy and paste in settings text boxes now share the app's common clipboard code; nothing changes in use.

### Upgrading

- Windows: run the installer over your current installation (it closes the running DropShelf first); for the portable version, replace DropShelf.exe.
- Linux: `chmod +x` the AppImage and run it; use your distribution's package manager for deb/rpm/pacman; unpack the portable tarball and run `bin/dropshelf`.

If you run into a problem, please open an [issue](https://github.com/wangmingkun148/DropShelf/issues). On Windows, attach the logs from `%LOCALAPPDATA%\DropShelf\Logs`; on Linux, from `~/.local/state/dropshelf/logs`.
