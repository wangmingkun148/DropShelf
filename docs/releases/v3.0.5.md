DropShelf 3.0.5 修正了 3.0.0 以来发现的问题，并让几项耗时的操作快了不少。原来的设置会保留。

### 修正

- **OneDrive 里的文件**：压缩、复制、移动和统计大小时，不再漏掉 OneDrive 等“按需下载”的文件和文件夹，也不再把它们当成链接而报错。
- **偶发的崩溃**：修正置物架菜单、关闭置物架和拖放时几处可能导致崩溃的问题。
- **表情字符**：截断较长的文字或文件名时，不再把表情字符截成半个（显示成方框，或者生成的文件名不合法）。
- **特殊的文件名**：文字的开头或附件的名称像 `NUL.tar.gz`、`aux.c` 这样时，生成的文件名前面会加一个 `_`。在 Windows 10 上这样的名字会被当成设备，原来文件可能写不出来。
- **临时附件的清理**：临时附件正被杀毒软件或预览占着时，隔一会儿会再试着清理，还不行就等下次启动时清理。
- **Windows 11 的贴靠布局**：鼠标停在主窗口的最大化按钮上时，会像其他窗口一样弹出贴靠布局。
- **设置文件**：设置或“最近关闭的置物架”的文件读不懂时（比如手动改错了一个字符），会先另存为同名的 `.bad` 文件，再改用默认值，不会直接被覆盖。

### 更快

- **压缩图片到指定大小**：重新编码的次数减少一半以上，结果不变。
- **一次放入或移除几千个文件**：查重和移除不再逐个比较，界面不会卡住。
- **压缩成 ZIP**：视频、照片、压缩包这类已经压缩过的大文件原样存入，速度快很多；压缩包可能比原来稍大一点，解压不受影响。
- **统计文件夹大小**：第一层的内容只列一遍。

### 升级

- 直接运行安装包覆盖安装，安装程序会关闭正在运行的 DropShelf。
- 便携版：退出旧版后，用新的 DropShelf.exe 替换旧的即可。
- 程序没有代码签名，第一次运行新程序时 Windows 可能会提示“Windows 已保护你的电脑”：点“更多信息”，再点“仍要运行”。

遇到问题欢迎到 [Issues](https://github.com/wangmingkun148/dropshelf/issues) 反馈，最好附上 `%LOCALAPPDATA%\DropShelf\Logs` 里的日志。

DropShelf 3.0.5 fixes issues found since 3.0.0 and makes several slow operations noticeably faster. Your settings are kept.

### Fixes

- **OneDrive files**: compressing, copying, moving and measuring folders no longer skips OneDrive "files on demand" (and similar cloud files), and no longer reports them as links.
- **Occasional crashes**: fixed several issues in the shelf menu, closing shelves and drag and drop that could crash the app.
- **Emoji**: shortening long text or file names no longer cuts an emoji in half (which showed up as a box or produced an invalid file name).
- **Special file names**: text that starts like `NUL.tar.gz` or `aux.c`, and attachments with such names, now get a `_` in front of the file name. Windows 10 treats such names as devices, so the file might not have been written.
- **Cleaning up temporary attachments**: when an antivirus scanner or the preview pane is still holding a temporary attachment, DropShelf tries again a little later, and otherwise cleans it up the next time it starts.
- **Windows 11 snap layouts**: hovering over the main window's maximize button now shows the snap layouts, like other windows.
- **Settings files**: if the settings file or the recently closed shelves file can't be read (for example after a typo while editing it by hand), it is saved as a `.bad` file next to it before the defaults are used, instead of being overwritten.

### Faster

- **Compressing images to a size limit**: less than half as many re-encodes, with the same result.
- **Adding or removing thousands of files at once**: duplicate checks and removal no longer compare every pair, so the shelf doesn't freeze.
- **Compressing to ZIP**: large files that are already compressed (videos, photos, archives) are stored as they are, which is much faster. The archive may be slightly larger than before; extracting works the same.
- **Measuring folder sizes**: the top level of a folder is listed only once.

### Upgrading

- Run the installer over your current installation. It closes the running DropShelf first.
- Portable version: quit the old version, then replace its DropShelf.exe with the new one.
- DropShelf isn't code-signed, so Windows may show "Windows protected your PC" the first time you run the new program. Click "More info", then "Run anyway".

If you run into a problem, please open an [issue](https://github.com/wangmingkun148/dropshelf/issues) and attach the logs from `%LOCALAPPDATA%\DropShelf\Logs`.
