DropShelf 3.1.8 修好了置物架里的东西拖不出去的问题。

### Linux 版

- **置物架里的图片、文件又能拖出去了**：3.1.6 加的 X11 拖放桥在“按住左键、光标在置物架上”时就把那块铺满屏幕的透明窗口挂了出来。从置物架往外拖的时候正好是这个状态，落点于是变成了我们自己那块看不见的窗口，拖到浏览器、聊天软件、文件管理器上都没有反应，松手只会看到拖动被取消。现在本程序自己正在拖出时不再挂这块窗口；从别的 X11 应用往置物架里拖不受影响。

### 升级

- Linux：AppImage 下载后 `chmod +x` 再运行；deb/rpm/pacman 用发行版的包管理器升级；便携版解压后运行 `bin/dropshelf`。

遇到问题欢迎到 [Issues](https://github.com/pingod/DropShelf/issues) 反馈，请附上 `~/.local/state/dropshelf/logs` 里的日志。

DropShelf 3.1.8 fixes items on the shelf not being draggable out.

### Linux

- **Images and files can be dragged out of the shelf again**: the X11 drop bridge added in 3.1.6 put its fullscreen invisible window up whenever the left button was held over a shelf. That is exactly the state you are in when dragging something out, so the drop landed on that invisible window of ours instead of the browser, chat app or file manager underneath, and letting go just cancelled the drag. The window is now left alone while DropShelf itself is dragging out; dragging from other X11 apps into the shelf still works.

### Upgrading

- Linux: `chmod +x` the AppImage and run it; use your distribution's package manager for deb/rpm/pacman; unpack the portable tarball and run `bin/dropshelf`.

If you run into a problem, please open an [issue](https://github.com/pingod/DropShelf/issues) with the logs from `~/.local/state/dropshelf/logs`.
