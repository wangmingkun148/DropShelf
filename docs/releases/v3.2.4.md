观察的文件夹来了新文件时，屏幕边缘探出置物架的一角（随机露出上角或下角），悬停转正，点一下置物架转一圈飞出来；新增“每个新文件放入独立置物架”；设置里观察的文件夹和屏蔽的应用列表往右缩进、底色深一点，一眼看出属于上面那项；Linux 版拖到微信、WPS 时按对方要的格式给，大图片和长文字也送得过去（由 @pingod 贡献）；Linux 版界面里不再写“Windows”“资源管理器”，选择屏蔽的应用时也不再只能选 .exe；Linux 版低性能模式选“自动”时，用电池或开了节能模式就会降低动画；修复 Linux 版纸牌风格的出场动画卡住、重启后语言和语言包要打开设置才生效，以及强调色选中圈上多出一条斜线。
