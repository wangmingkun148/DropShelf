DropShelf 3.1.9 修好了往 WPS 这类 XWayland 程序里拖东西时内容不对的问题。

### Linux 版

- **拖到 WPS 里现在是真正拖进去的内容**：从置物架往 WPS 这类跑在 XWayland 上的程序拖图片、文件时，Hyprland 会把 Wayland 的拖动转成 Xdnd 发过去，可是拖动期间它不让 X11 程序读任何 selection。对面拿不到数据，就退回粘贴剪贴板——剪贴板里是图片时会变成“乱码加一张图”，有时干脆什么都没发生。现在光标在 XWayland 窗口上停住以后，DropShelf 自己接管这次拖出，直接用 Xdnd 把文件列表和文字交给对方，不再经过合成器。拖到 Wayland 程序（浏览器、聊天软件、文件管理器）上仍然走原来的 GTK 拖动。
- **手势日志不再每次都记**：以前每次按住鼠标都会写一行“按住期间取到 N 次光标位置”，现在只在真识别出手势、或者这次按住被全屏程序之类挡住时记。

### 升级

- Linux：AppImage 下载后 `chmod +x` 再运行；deb/rpm/pacman 用发行版的包管理器升级；便携版解压后运行 `bin/dropshelf`。

遇到问题欢迎到 [Issues](https://github.com/pingod/DropShelf/issues) 反馈，请附上 `~/.local/state/dropshelf/logs` 里的日志。

DropShelf 3.1.9 fixes the wrong content being dropped into XWayland apps such as WPS.

### Linux

- **Dropping into WPS now inserts what you actually dragged**: when dragging images or files from the shelf onto an app running under XWayland, Hyprland converts the Wayland drag into Xdnd — but while a drag is in progress it does not let X11 clients read any selection. The target gets no data, falls back to pasting the clipboard (with an image in the clipboard that shows up as a garbled "image" placeholder, and sometimes nothing happens at all). Now, once the cursor rests over an XWayland window, DropShelf takes the drag over itself and hands the file list and text to the target with Xdnd directly, without going through the compositor. Dragging onto Wayland apps (browsers, chat apps, file managers) still uses the regular GTK drag.
- **The gesture log line is no longer written on every press**: it used to log "got N cursor positions while held" for every mouse press; now it is only logged when a gesture was actually recognized, or when gestures were paused during that press (fullscreen apps and the like).

### Upgrading

- Linux: `chmod +x` the AppImage and run it; use your distribution's package manager for deb/rpm/pacman; unpack the portable tarball and run `bin/dropshelf`.

If you run into a problem, please open an [issue](https://github.com/pingod/DropShelf/issues) with the logs from `~/.local/state/dropshelf/logs`.
