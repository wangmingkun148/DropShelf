# DropShelf for Windows

简体中文 | [English](README.en.md)

DropShelf 是一个 Windows 临时文件置物架。拖着文件晃一晃鼠标，或拖到屏幕边缘停一下，置物架就会出现在手边。先把文件放上去，切换窗口、打开目标文件夹后，再一次拖到资源管理器、聊天软件或浏览器里，不用再把两个窗口并排摆好。

**主要优点**

- 只在拖动时出现：晃动识别在独立线程上完成，不会拖慢鼠标；按住鼠标乱晃但没拖东西时不会误弹。
- 拖进拖出都和资源管理器一致：支持文件、文件夹、图片、文本、链接，以及浏览器、邮件和聊天软件里还没保存到磁盘的附件。
- 自带快速操作：压缩/解压、复制路径、移动到，也可以自定义“发送到文件夹”“压缩图片到指定大小”“用程序打开”。
- 误关可恢复：最近关闭的 10 个置物架都能重新打开。
- 轻量、安全：普通用户权限运行，不读取文件内容，不联网。
- Windows 11 风格界面，支持浅色、深色主题和中英文界面。

**为什么又做一个**

同类软件已经不少，DropShelf 难免有重复造轮子之嫌。不过它尽量解决了一些同类软件存在的问题：

- 用鼠标钩子识别手势，程序一忙鼠标就卡顿。DropShelf 改用原始输入（Raw Input），在独立线程处理。
- 没拖东西时晃鼠标也会弹出。DropShelf 先确认确实在拖动内容，才弹出置物架。
- 聊天软件拖出的图片，放下后源文件马上被删除，置物架上只剩失效的项目。DropShelf 会立即另存一份。
- 资源管理器在同一磁盘内移动文件后，置物架上仍留着已经移走的项目。DropShelf 能正确识别并移除。
- 拖到聊天软件或浏览器时被拒绝放下。DropShelf 会自动改为复制。

灵感来自 macOS 上的 [Dropover](https://dropoverapp.com)。DropShelf 是独立项目，与 Dropover 没有关联。

**说明**

- 本项目的代码由生成式 AI 编写。
- 软件的中文界面文字经过人工校对，英文由 AI 翻译。
- 为 Windows 11 开发并优化。Windows 10 及更早版本没有测试过，不保证可用。

## 下载

到 [Releases](https://github.com/wangmingkun148/dropshelf/releases/latest) 下载最新版：

- `DropShelf-Setup-版本号.exe`：安装包，推荐。
- `DropShelf-版本号-portable.zip`：便携版，解压后直接运行 `DropShelf.exe`。

## 使用方法

1. 运行安装包，或解压便携版后运行 `DropShelf.exe`。
2. 关闭主窗口后，程序继续在任务栏通知区域运行。
3. 在资源管理器、桌面、浏览器或聊天软件里拖住文件，快速来回晃动鼠标，置物架会出现在光标处；也可以拖到屏幕左、右或上边缘停一下，置物架会从边缘滑入。
4. 把文件放进置物架。之后拖动缩略图堆叠，可一次带走全部文件；在右上角“⋯”菜单中展开列表，可以单独或多选拖出。
5. 也可以按 `Ctrl+Shift+Space`（可在设置中修改）随时打开空置物架，再按 `Ctrl+V` 粘贴文件、图片或文本。

## 功能

### 呼出置物架
- 在独立线程上用原始输入（Raw Input）识别晃动。系统不必等待 DropShelf 处理完才移动光标，程序繁忙时也不会让鼠标卡顿。
- 识别到晃动后，在光标下放置一个肉眼不可见的探针窗口，由系统拖放机制确认确实在拖动文件、附件、图片或文本后才弹出置物架。按住鼠标晃动但没有拖东西时不会误弹。
- 支持左右、上下和斜向晃动，提供灵敏、均衡、稳健三档。
- 拖到屏幕左、右或上边缘停留即可呼出，停留时间可选 0.3 秒、0.6 秒或 1 秒。任务栏所在的位置和多显示器之间相邻的边缘不会触发。
- 呼出方式可选晃动、屏幕边缘或两种都用。程序运行时始终响应，不需要时直接退出即可。
- 对高回报率鼠标自动重新取样，掉头时的细小侧移不会打断识别。
- 弹出时整个窗口从来源方向滑入、内容从光标处展开；Windows 关闭了动画效果时直接显示。

### 置物架
- 收起时显示缩略图堆叠、数量角标和总大小；拖动堆叠即可整摞拖出。同时有文件和文字时只拖出文件，文字和链接留在架上。
- 在“⋯”菜单中展开或收起列表。列表显示文件名、大小和 Windows 文件类型，支持 Ctrl/Shift 多选、拖出所选、双击打开、右键菜单。
- 拖出使用与资源管理器相同的数据格式和拖动图像（缩略图堆叠 + 数量）。能正确识别资源管理器在同一磁盘“优化移动”的情况，被移走的项目会自动从置物架移除。
- 拖出默认移动文件（跨磁盘也一样），可在设置的“拖动目的”或置物架顶部的“移动/复制”按钮随时切换；按住 Ctrl 或 Shift 仍可临时改变。拖到只接受复制的程序（聊天软件、浏览器）时自动复制。
- 拖入时显示来源程序的拖动图像和“添加到置物架”等提示；不支持的内容会直接提示。拖到底部按钮栏时快速操作才会展开：与底部按钮排成一行、一一对齐，从光标所在的按钮向上长高；移回上方即收起。
- 默认“自动关闭空置物架”：拖出的文件会离开置物架，空了就自动关闭；关闭此项后复制出去的文件仍留在架上，可以再拖到别处。钉住的置物架空了也保持打开。
- 支持文件、文件夹、尚未落盘的附件（浏览器、邮件、聊天软件）、网页链接、图片和文本。
- 适配聊天软件：从临时文件夹拖出、拖放后马上被删除的图片和文件会立即另存一份；支持 PNG、JPG、GIF、DIB/DIBV5 图片数据，以及旧版 QQ 和只含图片的网页片段；拖出或复制到聊天软件的临时附件会多保留 10 分钟，避免对方读取时文件已被清理。
- 误关不用怕：关闭（包括退出程序时）仍有文件的置物架会保留在“最近关闭”中，最多 10 个，只记录路径和名称。可从设置的概览页（在主窗口旁打开）、托盘菜单或置物架“⋯”菜单中的“恢复上次的置物架”重新打开。
- 可同时打开多个置物架；可以钉住，清空后也不会关闭。
- 快捷键：`Esc` 收起或关闭、`Delete` 移除所选、`Ctrl+A` 全选、`Ctrl+C` 以文件形式复制、`Ctrl+V` 粘贴、`Enter` 打开。
- 小、中、大三档尺寸各自重新排版，文字不会被缩小。

### 快速操作
- 置物架底部可显示 0、2 或 4 个快速操作。2 个时与 4 个占用相同空间，按钮更大并显示名称；关闭时整个置物架都可以放入文件。
- 设置页按置物架上的排列显示当前操作及其位置（与置物架底部按钮一样排成一行：两个时为左、右，四个时从左到右为左一、左二、右二、右一）。把“更多操作”中的任一内置操作（压缩/解压、复制路径、移动到、属性、显示位置）或自定义操作拖到某个位置即可替换，两个位置之间拖动则互换。
- 自定义操作：
  - 文件夹：一键移动或复制到固定文件夹。
  - 压缩图片：压缩为不超过指定大小（如 200 KB）的 JPG，先降低画质、仍过大时再缩小尺寸；自动转正拍摄方向，透明部分铺白色。压缩后的图片替换置物架中的原图，原文件不变，方便直接拖到网页或聊天窗口。
  - 用程序打开：把文件交给指定程序，可用 `{files}` 指定参数中的位置。
- 点击按钮处理置物架中的项目（展开后只处理选中项）；拖动文件时也可以直接放到按钮上。
- 压缩生成的 ZIP 和解压出的文件夹放进旁边新开的置物架（原置物架为空时直接放入），方便直接拖走。压缩、解压、复制都不会覆盖已有的同名项目。
- 单独放入 ZIP 或 7z 时解压；7z 使用 Windows 自带的 tar，旧版 Windows 不支持时会提示。

### 设置与外观
- Windows 11 风格的设置窗口：云母背景、设置卡片、开关和分段选择。概览页用四张卡片进入常规、手势与置物架、快速操作、外观，卡片上显示当前设置，子页面左上角返回。
- 置物架在 Windows 11 上使用亚克力半透明材质和系统圆角；强调色可跟随 Windows 或从八种颜色中选择，并自动保证文字对比度。
- 支持跟随系统、浅色和深色三种主题。所有设置修改后立即生效并自动保存。
- 界面支持简体中文和英文：默认跟随 Windows 显示语言，可在“常规 > 语言”中切换，已打开的窗口、置物架和托盘菜单立即更新，无需重启。
- 概览页下方用缩略图堆叠显示最近关闭的置物架，默认一行，可展开全部，点击即可在主窗口旁恢复；没有记录时不显示。“快速上手”关闭后不再显示。
- 标题栏显示运行状态；右下角的版本号可打开“关于”窗口，查看程序、设置和日志的位置，以及退出和卸载。
- 首次运行显示带动画演示的四步教程，之后可在“常规”中重新查看。

### 系统集成
- 托盘图标：左键打开设置，右键可新建置物架、重新打开最近关闭的置物架、退出。
- 可选开机自动启动，启动时只在后台运行。
- 安装时可选添加到右键“发送到”菜单；把文件拖到程序图标上或用命令行 `DropShelf.exe --shelf 文件...` 也会打开置物架。程序已运行时会交给现有实例处理。
- 重复启动时唤醒已有窗口，不会出现第二个实例。

## 隐私与数据安全

- 放入普通文件时只记录路径，不读取也不复制文件内容；放入、移除、清空都不会改动磁盘文件。
- 来自临时文件夹的文件（聊天软件拖出的图片等）、尚未落盘的附件和拖入的图片会暂存在系统临时目录，关闭对应置物架时清理；意外退出留下的旧缓存会在下次启动时清理。
- 拖出时默认移动，由接收方（如资源管理器）完成移动；“移动到”和文件夹类自定义操作会移动文件，同名时自动保留两份。压缩图片只生成新文件，不改动原图。
- 最近关闭的置物架只记录文件和文件夹的路径与名称（不含文本、链接和临时附件），最多 10 个，可在设置中清除。鼠标位置只在内存中用于识别手势，不会保存或上传。
- 程序以普通用户权限运行，不需要管理员权限。

## 安装与卸载

安装包默认安装到当前用户的本地程序目录（`%LOCALAPPDATA%\Programs\DropShelf`），不需要管理员权限，可直接覆盖升级 1.0 版，原有设置会自动迁移。卸载可通过“设置 > 应用 > 已安装的应用”、开始菜单，或程序目录中的 `卸载 DropShelf.exe`；卸载会关闭正在运行的 DropShelf，并移除程序文件、快捷方式和开机启动项，个人设置与日志默认保留。便携版没有安装记录，完全退出后删除文件夹即可。

## 数据位置

- 设置：`%LOCALAPPDATA%\DropShelf\settings.json`
- 最近关闭的置物架：`%LOCALAPPDATA%\DropShelf\history.json`
- 运行日志：`%LOCALAPPDATA%\DropShelf\Logs`（自动删除 14 天前的日志）

## 系统要求

- Windows 11，64 位。Windows 10 及更早版本没有测试过，不保证可用
- 发布版 EXE 已包含运行环境，无需另行安装 .NET

## 从源码构建

项目使用 .NET 10 和 WPF，不依赖第三方 NuGet 包。

```powershell
dotnet build .\DropShelf.sln -c Release
dotnet run --project .\src\DropShelf\DropShelf.csproj
```

运行测试：

```powershell
dotnet run --project .\tests\DropShelf.Tests\DropShelf.Tests.csproj
```

生成便携版和安装包（需要 Inno Setup 6 或 7）：

```powershell
.\installer\Build-Installer.ps1
```

生成的文件在 `artifacts\installer`（安装包）和 `artifacts\win-x64`（便携版）中。

开发调试时可设置环境变量 `DROPSHELF_INSTANCE`（独立实例，可与已安装版本同时运行）、`DROPSHELF_SETTINGS_PATH` 和 `DROPSHELF_LOG_DIRECTORY`。

## 项目结构

- `src/DropShelf/AppController.cs`：应用总控，协调设置、手势、置物架、托盘和窗口。
- `src/DropShelf/Services/Gestures`：鼠标原始输入监听、晃动识别与屏幕边缘停留。
- `src/DropShelf/Views/ProbeWindow.cs`：确认拖放内容的探针窗口。
- `src/DropShelf/Shelves/ShelfManager.cs`：多个置物架的创建、复用与关闭。
- `src/DropShelf/Views/ShelfWindow.xaml`：置物架界面；`MainWindow.xaml`：设置；`OnboardingWindow.xaml`：教程。
- `src/DropShelf/Services`：拖入数据解析（含聊天软件适配）、原生拖出、快速操作与图片压缩、最近关闭的置物架、剪贴板、缩略图、主题、托盘、快捷键等。
- `src/DropShelf/Localization`：中英文界面文字；XAML 通过 `{l:Loc 名称}` 引用，切换语言时自动刷新。
- `src/DropShelf/Themes`：颜色、图标与 Fluent 风格控件样式。
- `src/DropShelf/Interop`：Win32、DWM 与 Shell 接口。
- `tests/DropShelf.Tests`：自动化测试。

## 发布新版本

1. 修改 `DropShelf.csproj`、`app.manifest` 和 `installer` 下两个 `.iss` 文件中的版本号，合并到 `main`。
2. 在 GitHub 的 Releases 页面点“Draft a new release”，新建标签 `v版本号`（如 `v2.0.8`，须与版本号一致）并发布。
3. GitHub Actions 会自动编译安装包和便携版，几分钟后附加到这个 Release 上。也可以直接推送标签：`git tag v2.0.8 && git push origin v2.0.8`。
